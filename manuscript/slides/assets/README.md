# EMERGE slide resources

- `github-invertocat.png`: official black GitHub Invertocat with clear space,
  extracted from the logo package at <https://brand.github.com/GitHub_Logos.zip>.
- `arxiv-logo.png`: current arXiv wordmark, mirrored from the official arXiv
  brand asset at
  <https://commons.wikimedia.org/wiki/File:ArXiv_logo_2022.svg>.
- `qr-arxiv.png`: encodes <https://arxiv.org/abs/2606.14840>.
- `qr-github.png`: encodes <https://github.com/tXiao95/csdr>.

The QR codes use black modules on white with a four-module quiet zone and high
error correction for projection and phone scanning.
